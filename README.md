## Запуск и тесты

Нужен Python 3.10 или новее. В PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[test]'
.\.venv\Scripts\python.exe -m mtp_lab8
.\.venv\Scripts\python.exe -m pytest -q
```

После установки также доступна команда `mtp-lab8`. При запуске программа
создаёт три учебные задачи, отмечает две выполненными и выводит отчёт.

`Task.title` удаляет пробелы по краям и отклоняет пустое название.
`count_completed` принимает любой итерируемый источник задач.
`TaskRepository` задаёт операции хранения, а реализация в памяти
держит задачи в словаре. Генератор отчёта обращается к интерфейсу репозитория.

Для каждой строки отчёта запускается отдельная корутина. `asyncio.sleep`
имитирует ожидание ввода-вывода, а `gather` запускает корутины совместно
и возвращает результаты в порядке задач. Тест проверяет, что вторая корутина
успевает запуститься, пока первая ждёт её сигнала.
